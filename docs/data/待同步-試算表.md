## 補登方式

端點恢復後，逐筆以下列格式 POST（欄位內容取自 `docs/data/records.json` 對應列）：

```
curl -sL "$BASE" -H 'Content-Type: application/json' \
  -d '{"token":"muju-trace-2026","company":"...","ticker":"...","eventDate":"...", ...}'
```

亦可直接於試算表手動貼上——`records.json` 的欄位名與試算表欄位一一對應
（company 公司名稱／ticker 股票代號／eventDate 事件日期／eventType 事件類型／summary 事件摘要／
reading 軌跡判讀／label 判讀標籤／entry 切入點建議／priority 切入優先級／related 關聯公司／sources 來源連結）。
