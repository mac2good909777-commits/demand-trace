# 南茂科技（8150）— 需求軌跡檔

## 定位

A級｜購置方向｜**由 C 線（工業監控產業新聞）點名而新增，2026-08-28 建檔**

## 軌跡摘要（2026-08-28 建檔）

記憶體與驅動IC封測大廠，台灣主力基地在**新竹湖口**與**苗栗竹南**——竹南在本案監控區域內。
2026 年出現兩個方向一致的訊號：

**訊號一（購置行為已發生）**：2026/03/10 向群創光電購入其位於**南部科學園區的模組廠**，
交易總金額約 8.8 億元。標的雖在台南、不在監控區域，但意義在於**南茂會用「買現成廠」解決產能**，
不是只走園區配地——這是判斷它在竹南／湖口是否也會買現成廠的關鍵前例。

**訊號二（兩年高強度擴產宣示）**：2026/08/11 第二季法人說明會，宣布將**資本支出占營收比重
由原本 20% 以下大幅調升至 25% 以上，且 2027 年維持同一水位**，啟動為期兩年的高強度投資期。
動因是記憶體客戶擴充後段封測產能需求，以及手機、ASIC、**AI ASIC**、光通訊／矽光子等新產品
陸續進入投資與量產階段。同場說明今年底新一批高階測試機台將陸續到位。

**訊號三（台商回流加碼）**：2026/08/26 媒體報導南茂透過台商回流方案宣布加碼投資，
同期台商回流累計投資額突破 6,000 億元。台商回流案通常伴隨購地建廠或擴建既有廠區。

## 關鍵判讀

**這是一檔「宣示已出、落點未明」的案子——切入時機在最前面。**

到 2026-08-28 為止，南茂公告的是**資本支出比重**，不是**用地標的**。MOPS 近期無土地或廠房
取得公告。依本案訊號時序模型（重訊＞新聞＞＞實登），現在處在「新聞先行、尚未進入公告階段」，
與崇越 8/17 法說會那條線同一型態——**這種時點打進去，對方還在盤算，我們的資訊才有價值；
等重訊出來就已經簽約了。**

**兩年高強度資本支出的空間含意**：資本支出占營收 25% 以上、連續兩年，而且是「機台先到位、
再談產能」的節奏（今年底新一批高階測試機台到位）。**機台先到、廠房後補，中間就是短期空間缺口**——
這正是京元電子在銅鑼四廠興建期間先向立織承租苗栗頭份廠房的同一情境。竹南／頭份／湖口一帶
**可即刻進駐、電力充足的現成廠房**，對南茂是有用的。

**第二層（更容易成交的一批）**：封測擴產會帶動測試治具、載板、化學品、氣體、無塵室工程與
物流協力廠在竹南／頭份找點。這批量體 300–2,000 坪、決策快、租買皆可。

## 待查（下一輪深研補齊）

1. 竹南廠區確址、地號、現有土地與建物坪數，以及**廠區內外有無可併購鄰地**
2. 2026/08/11 法說會的資本支出**絕對金額**與其中土地／廠房佔比
3. 「台商回流加碼」的投資計畫書落點縣市——若指向竹南，分數立即再上調
4. 統編、董事會與決策層級（用地決策在總部或廠端）、資產／廠務窗口分機
