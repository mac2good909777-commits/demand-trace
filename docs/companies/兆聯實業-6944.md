## 軌跡判讀

**判讀標籤：擴張（連續購置）**

### 這是彰濱版的「大立光同街逐門牌收購」

| | 大立光（3008） | **兆聯實業（6944）** |
|---|---|---|
| 掃街位置 | 台中南屯**工業區21路**（2、19、23 號）＋西屯、精科 | **彰化鹿港工業西七路**（1-32、1-42 號） |
| 筆數／期間 | 5 筆／2026 上半年～8 月 | **2 筆／2026 年 3 月～7 月（4 個月）** |
| 單筆量體 | 5.6～30.8 億 | **1.8～2.84 億（授權 2～3 億）** |
| 交易方式 | 雙方議價、**無經紀人** | 雙方議價、**無經紀人** |
| 估價者 | 君鴻／各案不一 | **兩案同一家：誠正（林金生）** |
| 用途載明 | 「未來擴充產能需求」 | **「作為廠房擴充使用」** |
| 決策 | 董事長核決 | **董事會授權董事長全權簽約** |

四項共同特徵——**同一條路、同一家估價師、同樣寫廠房擴充、同樣無經紀人**——
指向同一種採購行為：**已鎖定街廓、逐個門牌談、沒有仲介介入**。
1-32 號（土地 938 坪）→ 1-42 號（土地 2,161 坪），四個月內面積翻 **2.3 倍**，
是「先小後大、確認可行後加碼」的節奏，不是機會性置產。

### 基本面支撐（不是為了置產而買）

- **在手訂單 277 億元創歷史新高**（2026 Q2 法說會），**7 月再獲 50 億大單尚未入帳**
- 純益率 **16.8%** 攀上高峰；2026 Q1 營收年增逾 50%
- 公司對外宣示 **今年整體產能至少提升三成**
- 美國為未來兩年重要成長動能：亞利桑那廠一期 **195 億**、2028 完工，美國員工今年倍增至百人

台積電資本支出持續墊高 → 廠務水系統工程需求上行 → 兆聯的產能瓶頸落在**預組裝與管件加工的實體空間**。
鹿港兩筆的性質推測為**系統模組預組裝／管件加工基地**，與彰濱既有金屬加工聚落相容。

### 尚未確認的兩件事

1. **鹿港兩筆是否已完成交割？** 兩則都是「董事會決議＋授權額度」，**未見後續成交金額公告**。
   115/03/12 案距今 **171 天**、115/07/03 案距今 **58 天**，依「重訊≈私契簽約 → 公契 → 過戶」的時間軸，
   3 月那筆應已過戶，**實價登錄約 2026 Q4 可後驗**（列入實登步驟的追蹤點）。
2. **產能提升三成的落點在鹿港還是屏東？** 屏東科技產業園區 5 億租地委建（115/07/03，契約相對人待定）
   與鹿港兩筆是同一天／不同天的決議，代表南北同時擴點。若主力在鹿港，後續還會再買。

## 經營建議

- 需求機率（未來12個月）：**高（88 分）**
- 分數組成：連續購置 **+35**／時近（115/07/03，58 天，≤3 月）**+20**／區域（彰化鹿港）**+10**／
  新鮮未接觸 **+10**＝ **75**；再加「同街逐門牌模式已成形＋在手訂單創高＋今年產能目標 +30%」權重 **+13** ＝ **88**
- 金額項不加分（單筆授權 2～3 億，未達 3 億級距）——**但這正是它被同業忽略的原因**
- 時間軸：115/07/03 重訊 ≈ 私契簽約 → 交廠 4 個月～1 年 → 推估 **2026/11～2027/07** 完成點交；
  115/03/12 那筆推估已過戶，**2026 Q4 實價登錄可後驗成交單價**（屆時即得彰濱鹿港的行情錨點）
