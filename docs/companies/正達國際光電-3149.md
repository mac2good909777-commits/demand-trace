## 軌跡判讀

**判讀標籤：收縮**

依大宇範式，處分不等於經營不善——但判斷要看同期有沒有購置或擴產。
正達屬光電玻璃蓋板本業長期收縮者，**同期查無購置或擴產動作**，
因此本筆判為**收縮**，而非資產重配置。

與同一條路上億光電子處分銅鑼廠（115/08/11 由信邦以 34.58 億標得）屬同一類型：
**本業收縮的光電廠釋出，半導體／電子廠承接。**

### 為什麼只給 C 級

列 C 級持續觀察的理由只有一個：**尚未查清它是否還持有其他中部資產。**

一家剛把 14,630 坪建物脫手的公司，如果名下還有廠，下一筆的機率高於一般公司。
但在查清之前不給更高分數，也不安排接觸動作——
**本則目前的價值是把交易對手記進系統，不是立刻開發。**
