## 一、專案目標

追蹤中部（台中/彰化/南投/苗栗/雲林/嘉義）公司的經營軌跡——**購置、處分、產業鏈動態**——
交叉判讀真實意圖，在需求成形的最早時點切入：處分＝幫它賣、購置＝幫它找、產業鏈＝追交易對手。
Claude 角色＝監控員＋經營協作教練（每天回看 Mac 的經營進度並給下一步）。

## 二、核心方法論（Mac 定調，勿改）

1. **訊號時效權重：重訊 ＞ 新聞 ＞＞ 實價登錄**（同一事件以最早訊號源起算時效）
2. **時間軸模型**：重訊≈私契簽約 → 交廠 4個月~1年 → 公契(謄本原因發生日) → 過戶 → 再1-2月實價揭露
   （實證：環鴻購明基三豐精科廠，重訊114/08、過戶115/08/05）；交廠前3-6個月＝賣方安置需求高峰
3. **大宇範式**：處分≠經營不善，須交叉同期購置判讀（資產活化/產能重配置）；交易相對人一律追蹤
4. **注意力導向評分**：排序＝「今天該把注意力放哪」——已關注(active/有進度紀錄且無新事件) **-25**、
   新鮮未接觸(事件≤30天無紀錄) **+10**、新事件出現取消-25重新拉高。基礎分見排程 prompt
5. 公司md：重訊原文全文貼入（公開申報資料）；新聞只摘要＋連結（著作權）
