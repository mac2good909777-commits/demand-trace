## 公司背景

- 1996 年推出**全國第一台由國內自行生產製造的懸掛式烘碗機**，短短數年掌握市場**七成以上代工**，
  成為**全國最大專業烘碗機生產者**。
- 產品線：烘碗機、瓦斯爐、IH 爐、排油煙機、熱水器及各式嵌入式廚房電器（歐化廚具配件研發製造）。
- **第二代侯劭諺已接班**，31 歲接手時對外放話「我要幹掉櫻花」；
  **2016 年設越南廠**生產中低價產品外銷東南亞，同期對外表述「**翻新台灣廠**」。
- 品質政策上以「完全台製」為訴求（曾對外表示若查出一顆螺絲為中國製即全數退貨）。

## 軌跡判讀

**判讀標籤：資產活化（非被迫遷廠）**

**這家不是科宏，話術不能照抄。** 兩案的量體與性質差很多：

| | 科宏工業（8/25，30.8 億） | 喜特麗國際（8/28，6.512 億） |
|---|---|---|
| 建物坪數 | **7,054.01 坪**（整廠） | **561.79 坪** |
| 土地坪數 | 6,292.14 坪 | 1,456.84 坪 |
| 建地比 | 1.12（正常廠房） | **0.386（低度利用）** |
| 標的性質 | 2015 年才設的**研發／新製程基地** | 低度利用之舊廠地 |
| 集團營運重心 | 台中（太平廠、西屯工業區三路14號） | **新北新莊＋越南廠** |
| 安置需求 | **硬需求**，3,000-5,000 坪級 | **不確定，量體小** |

建物只有 561.79 坪、建地比 0.386，土地 1,456.84 坪才是交易主體；
集團營運重心在新莊與越南。**本案八成是處分低度利用的台中土地資產，不是被迫遷廠。**
開口若說「幫您找新廠」會被當成沒做功課。

### 三題待查證（第三題才是真正的價值）

1. **23 號廠內現在是否還有在製產線？交廠（點交）時程排到什麼時候？**
2. **侯劭諺對外講過「翻新台灣廠」——指的是新莊還是台中？**
   若是台中，那賣掉 23 號之後必然要另覓新址，這才是需求所在。
3. **喜特麗及侯氏家族名下在台中或中部是否另有廠房、土地部位？**
   ← **這題最可能生出第二件委託。**

它剛完成一筆 6.5 億處分、對不動產價格與交易流程的認知是全新的，
**這是談後續賣方委託最好的時機**——比冷開發任何一個地主都容易。
