### 📌 給未來每日排程的修正（請一併改進 SKILL.md）

SKILL.md 寫的是：
```
新監控公司：POST action=watch 並同步 watchlist.json
```
並暗示與記錄分頁一樣用扁平欄位（`company` / `ticker` / `reason`）。
**實測結果：扁平欄位會回 `{"ok":true,"added":0}`——看起來成功，其實一列都沒寫。**
前幾輪「`action=watch` 自封鎖起全數失敗」的判斷，**有一部分其實是格式錯誤，不是網路封鎖。**

正確格式是包在 `rows` 陣列裡：
```json
{"token":"muju-trace-2026","action":"watch",
 "rows":[{"company":"金雨","ticker":"4503","reason":"..."}]}
```
回傳 `{"ok":true,"added":1}` 才是真的寫進去。

⚠️ **另一個要注意的行為：`action=watch` 不會去重**，同一家連送三次就會產生三列。
送出前要先 `?list=watch` 確認該公司不在名單上。
