### 先把兩個園區分清楚（這是前兩輪一直沒定案的題）

| | **臺中產業園區** | **臺中港科技產業園區** |

| 位置 | **臺中市西屯區**（大肚台地東側，跨及南屯） | **臺中市梧棲區**（大成路一帶） |
| 規模 | **580 公頃**、產業園區1路～42路（舊稱工業區一路～四十二路）、**1,027 家工廠** |臨港工業帶 |
| 貴公司在此 | **委託標的**：地號 **200／227**、廠登 **0227-00**、電話 **04-2359-1315** | **已售出**：大成路16號 4,253.27 坪（→信邦 3.4 億）；登記地大成路18號 |

兩地相距約 15 公里，**是兩個不同的園區**。
因此前一輪提出的「信邦要在台中港園區承租土地 ⟷ 進欣昱台中產業園區土地擬興建出租」
這條配對線 **不成立**——信邦要的地必須在梧棲，不在西屯。**此線本輪作廢，勿再對信邦提案。**

### 🟢 但同一個查證打開了更值錢的一條

而大立光（3008）2026 年五筆購地中——

**四筆全部落在臺中產業園區內**（第五筆精科一路8、10號在相鄰的精密機械科技創新園區）。
**貴公司的委託標的與大立光正在逐門牌掃街的區域，是同一個園區。**

大立光的行為特徵（可直接當談價素材）：
**今年五筆合計 63.00 億、五筆全部照估價全額吃下（最大折讓僅 0.7%）、雙方議價、無經紀人、董事長核決。**

### ⚠️ 但先查證，不要直接打電話說「大立光會買你的地」

- 臺中產業園區 **580 公頃、1,027 家廠商**，「同園區」≠「同街廓」。
- idbpark 只登錄「**地號 200／227**」，**未載地段**。
  **必須先查出地段與確址**，才知道與大立光文山段叢集（工業區21路一帶）的實際距離。
- 大立光的採購邏輯是**以總部為圓心就近整併**，五筆全部緊貼總部、完全不外跑。
  **距離是決定性變數**，這一步跳過去就會變成空歡喜。

### 因此本輪的動作順序（先內後外）

1. **內部先查**：調委託標的謄本／地籍圖，確認**地段名稱、地號、確址、面積、分區**，
   並在地圖上量出與工業區21路的距離。
2. **打通電話**（改撥 **04-2359-1315**，非梧棲總機 04-2698-1155）：
   ①售價與條件想法有無變動（距 8/9 委託已 21 天）②遷回大成路18號時程 ③「興建出租」線是否仍在。
3. **確認距離夠近後**，才把大立光那組成交數字（43.0／44.7／45.0 萬/坪）帶進去談價——
   **這組數字同時是委託方的定價依據，也是我方後續遞件給大立光的入場券。**

### 可用的第二組談價素材（貴公司自己的成交）

115/04/23 售予信邦的梧棲大成路16號廠房 **4,253.27 坪、不超過 3.4 億**，
捷丞不動產估價師聯合事務所（楊秀鳳）估價 **340,626,192 元**，**雙方議價、成交幾乎等於估價**。
談台中產業園區這塊地的定價邏輯時，**它自己就是最有說服力的比較基準**。
