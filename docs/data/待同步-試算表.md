## 日後怎麼補

若再出現寫入失敗累積，直接跑：

```bash
python tools/backfill_sheet.py            # 乾跑，只列出缺哪些
python tools/backfill_sheet.py --write    # 確認後實際寫入
```

判重鍵＝(公司, 事件日期, 事件類型)，與每日排程一致。腳本已處理兩個坑：

1. **日期格式**：試算表回 ISO UTC 時間戳，民國年被當成西元年序列化，
   古早年份套用台北 LMT（+8:06）而非 +8:00 —— 故用「加 12 小時取最近一天」正規化。
2. **只到月的日期**（如 `2026/01`）寫入後會被補成完整日期，反向比對不到 —— 改用年-月前綴比對，
   避免重複寫入。
