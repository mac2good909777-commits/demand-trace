## 軌跡判讀

### 【2026-09-25 建檔】買方與賣方兩種劇本都可能

私募用途把「**償還銀行借款**」與「**購置資本支出**」並列：
- (a) 轉虧為盈後補產能 → 購置需求；
- (b) 去年大虧、以私募引進策略投資人改善財務 → 若同時處分資產，即成**賣方線**。

**判讀的鑰匙是應募人身分**：同業或上游策略投資人＝整併前兆、廠區可能重組；財務投資人＝單純補血。應募人會在私募定價重訊揭露。

### 判讀：兩個相反劇本可以收斂了

9/25 建檔時寫「(a) 購置／(b) 處分兩種相反劇本都可能」。本輪四件事同時成立，**賣方劇本升權**：

1. 熬過 94 人做四休三（且勞工局稱未撤回通報）
2. 2025 年 EPS -2.67
3. 一年內連兩輪對外拿錢（2025/11 現增 ＋ 2026/09 私募）
4. 私募用途明寫「償還銀行借款」，董監另有 8.13% 質押

**一家在補資產負債表的公司，處分閒置廠房是自然的下一步——而它的廠就在台中大甲幼獅工業區工六路 3 號＝監控區域內。** 這是 C 升 B 的真正理由。

**第二個判讀：談判對象要改。** 業強 22.63% 高於董事長謝瑞木的 9.73%，且有兩席董事、連兩輪出錢——資產決策不會只在謝家手上。

⚠️ **不把話說死**：私募用途同時列「購置資本支出」，2026 Q2 EPS 已回正，方向仍是兩面的。**真正的分水嶺是應募人身分**——同業或策略投資人 → 擴產；財務投資人或關係人 → 補血兼可能瘦身。
