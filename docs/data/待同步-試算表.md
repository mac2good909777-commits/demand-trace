## 2026-09-05：`action=watch` payload 形狀錯誤，靜默漏寫 29 家（**已修復並全數回補**）

### 症狀
`tools/_watch_new.py` 舊寫法把公司欄位**攤平在 JSON 最上層**送出：

```json
{"token":"...","action":"watch","company":"某某","ticker":"...","reason":"..."}
```

Apps Script 一律回 **`{"ok":true,"added":0}`** —— `ok:true` 看起來成功，實際上一列都沒寫進「觀察名單」分頁。
因為過去只看 `ok` 不看 `added`，這個錯誤**從未被發現**。

### 影響範圍
2026-09-05 比對試算表（34 家）與 `watchlist.json`（63 家），確認**漏寫 29 家**，
其中包含全名單分數最高的兩家：

> 大立光、矽品精密工業、崇越、台化、喜特麗國際、友達、南茂科技、美光台灣、惠來產創、振鋒企業、
> 台灣翔登、鈞興-KY、南亞科技、廣達、巧新科技、光罩、全新光電、巨大、永泉豐企業、聯詠、
> 亞泰冷藏、榮全化工機械、富采光電、錼創科技-KY、台塑新智能科技、銳澤實業、漢華水處理工程、
> 興光熱處理廠、和泰服務行銷

### 正確寫法
公司必須包在 **`rows` 陣列**裡（其他鍵名 `watch`／`items`／`companies`／`list`／`data` 實測皆回 `added:0`）：

```json
{"token":"muju-trace-2026","action":"watch","rows":[{"company":"...","ticker":"...","reason":"...","added":"2026-09-05"}]}
```

### 處置
- `tools/_watch_new.py` 已修正為 `rows` 形狀，並加上 `added=0` 的自動告警
- `tools/_watch_backfill_20260905.py` 已將 29 家分 6 批全數補寫，回應累計 `added` 合計 29，試算表已補齊
